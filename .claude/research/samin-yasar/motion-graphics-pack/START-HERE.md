# Claude Motion Graphics Pack

Thanks for grabbing this. It goes with my video "Claude Just Changed Motion Graphics Forever! (Tutorial)": https://youtu.be/03aOyIKmQak

The fastest path:

1. Install the skill. Claude Code: run `git clone https://github.com/Samin12/claude-ads-skill ~/.claude/skills/motion-ads` and start a new session. claude.ai or the Claude desktop app: Settings > Skills (under Capabilities) > upload `skill/motion-ads.zip`.
2. Read `Claude Motion Graphics - Guide.pdf` (11 pages, about 15 minutes).
3. Level 1: make a folder with your logo, product photos and screenshots, open Claude Code in it, and paste prompt 0 from `COPY-PASTE-PROMPTS.txt`. Approve the storyboard, then let it build.
4. Level 2: connect Higgsfield to Claude (https://higgsfield.ai/s/mcp-saminyasar_-UzcUlZ > MCP > Add Higgsfield to Claude), put your footage in a folder, and run prompts 2.1 and 2.2.
5. Level 3: put real photos of your product in `refs/`, run the meta-prompting prompt, edit what Claude writes, approve the storyboard, then build.
6. Tell Claude your credit budget before any paid job. `higgsfield/credit-log-template.md` is the log to keep.

What's in here:

- `Claude Motion Graphics - Guide.pdf`: the guide.
- `COPY-PASTE-PROMPTS.txt`: every prompt, in order.
- `skill/motion-ads.zip`: the motion-ads skill. `skill/INSTALL.md` has the install steps.
- `higgsfield/`: setup, the models that worked, and the credit log template.
- `examples/`: the storyboard and the review sheet from my Level 1 build.
- `LINKS.html`: every link.

The example is a spec ad for the TRMNL e-ink display, made for a tutorial. Not affiliated with TRMNL.
